# College Website

A simple college website prototype developed using HTML, CSS, and JavaScript.

## ✨ Features

- College information
- Department details
- Principal's message
- Contact section
- Contact form interaction
- Student registration form
- Responsive and clean layout

## 🛠️ Technologies Used

**HTML5** • **CSS3** • **JavaScript**

## 🎯 Purpose

This project demonstrates the fundamentals of front-end web development,
including page structure, styling, forms, navigation, and JavaScript-based
user interaction.
